## 📖 About The Project

**English Janala Resources** is an educational web application created to make English vocabulary learning easier and more interactive.

Users can explore different vocabulary lessons, view word meanings and examples, and practice English through a simple and responsive interface.

The project focuses on creating a clean learning experience while using JavaScript to dynamically display and manage learning content.

## 🛠️ Technologies Used

* **HTML5** — Semantic page structure
* **CSS3** — Styling and responsive design
* **JavaScript (ES6)** — Application logic and interactions
* **DOM Manipulation** — Dynamic content rendering
* **API** — Fetching vocabulary and lesson data
* **Git & GitHub** — Version control and source code management
* **GitHub Pages** — Deployment

## ⚙️ How To Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/code-by-nusrat/english-janala-resources.git
```

### 2. Navigate to the project folder

```bash
cd english-janala-resources
```

### 3. Open the project

Open `index.html` directly in your browser.

For a better development experience, you can use **VS Code Live Server**.

### 4. Run with Live Server

1. Open the project in VS Code.
2. Open `index.html`.
3. Right-click the file.
4. Select **Open with Live Server**.

The project will then open in your browser.
